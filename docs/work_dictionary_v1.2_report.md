### 1.1 지표 산식 정의

- **단위**: 셀 단위. `대표 작품(원작)` 칼럼 1셀 = 1 레코드이며, 한 셀이 정확히 하나의 분류(matched/unmatched/uncertain/noise/empty)에 속한다. 복수 작품 병용 셀은 세그먼트로 분해 저장되지만 통계는 셀 기준
- **매칭률** = 매칭 성공 셀(작품 코드 1개 이상 부여) ÷ 전체 셀. **빈 셀 1,614개를 분모에 포함**한다 (참고용으로 빈 셀 제외 유효 셀 분모 97.45% 병기)
- **노이즈 셀** = 코드가 없으면서 셀 전체 원본 값이 사전 `metadata.llm_decisions`의 `noise` 결정값(72종)과 정확히 일치하는 셀. 엔진 노이즈 필터(`noise_terms`)에 걸리지만 LLM 결정이 없는 값은 보수적으로 잔여 미매핑에 유지한다 (예: `스티커`, `키링` 등 v1.0 시절 필터 분)
- **판단 불가 셀** = 코드가 없으면서 정규화 결과가 `판단 불가`인 셀 (사전 `llm_decisions` uncertain 130종 기준)
- **처리율** = (매칭 성공 + 판단 불가 + 노이즈 셀) ÷ 전체 셀 — 코드 부여 또는 명시 분류까지 완료된 비율. 잔여 미매핑만 사람 확인 대상으로 남는다
- **토큰 단위 참고치**: 병용 셀은 세그먼트별로 매칭되므로 methods(토큰) 합계는 셀 수보다 클 수 있다. 토큰 단위 상세는 `matching_stats_v1.2.json`의 `methods` 참조

## 6. 재현 방법

```bash
# v1.1 상태에서 v1.2 사전 빌드 (LLM 배치 매핑 적용)
cp analysis/WORK_DICTIONARY_v1.1_backup.json WORK_DICTIONARY.json
python3 scripts/llm_batch_map.py --apply --mapping analysis/llm_mapping_v1.2.csv \
    --new-version 1.2 --updated 2026-09-21

# 전체 회차 정규화 + 통계 재수집 + DB 재구축 (적용 후 최종 산출물 기준)
python3 pipeline.py --all
python3 scripts/analyze_works.py --tag v1.2   # 셀 단위 통계·unmatched 재수집
python3 scripts/generate_v1_2_report.py      # 본 보고서 재생성
```
