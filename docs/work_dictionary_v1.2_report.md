## 6. 재현 방법

```bash
# v1.1 상태에서 v1.2 사전 빌드 (LLM 배치 매핑 적용)
cp analysis/WORK_DICTIONARY_v1.1_backup.json WORK_DICTIONARY.json
python3 scripts/llm_batch_map.py --apply --mapping analysis/llm_mapping_v1.2.csv \
    --new-version 1.2 --updated 2026-09-21

# 전체 회차 정규화 + DB 구축
python3 scripts/analyze_works.py --tag v1.2   # 통계 측정
python3 scripts/build_db.py                    # DB 재구축
# 또는 단일 진입점: python3 pipeline.py --all
```
