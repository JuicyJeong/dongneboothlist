### 카테고리 6: 다중 작품 표기 (하나의 셀에 여러 작품)

구분자(`,` `/`)로 여러 작품을 한 셀에 표기한 경우. **분리 정책 결정 필요**.

| 패턴 | 예시 (빈도) | 특징 |
|---|---|---|
| 콤마 구분 | `괴담출근,이착헌`(8) `슬램덩크,가비지타임`(4) | 부스가 2개 이상 작품 다룸 |
| 슬래시(시리즈명) | `페이트/그랜드 오더`(41) `포켓몬스터 스칼렛/바이올렛`(5) | 단일 작품명의 일부 |
| 슬래시(다중작품) | `슬램덩크/가비지타임`(1) `원신/스타레일`(3) | 부스가 2개 작품 다룸 |

> **주의**: `/`는 시리즈명 일부(페이트/그랜드 오더)인지 다중 작품 구분자인지 문맥 판단 필요
> **해결책**: 다중 작품은 첫 번째를 대표 작품으로 하거나, 별도 컬럼/배열로 분리

## 권장 정규화 프로세스 (4단계)

```
[1단계: 문자열 정규화]
  원본 스트링 → 공백제거비교키 생성 → 표준 띄어쓰기 매핑

[2단계: 별칭 매핑]
  약칭 사전(데못죽→데뷔 못 하면 죽는 병 걸림 ...) 적용
  괄호 내 약칭 자동 추출 → 사전 보완

[3단계: 다중 작품 분리]
  구분자(,)로 분리 → 첫 번째를 대표 작품, 나머지는 보조
  슬래시(/)는 문맥 판단 (시리즈명 vs 구분자)

[4단계: 예외 처리]
  노이즈(.) → 빈값
  비창작물(오리지널/수공예) → 메타 카테고리
  시리즈명 → 상위 그룹 매핑
```

### 산출물 예상

| 산출물 | 설명 |
|---|---|
| `work_alias_dictionary.json` | 약칭 → 정식명 매핑 사전 |

| 정규화된 `*_부스정보.csv` | 원본 보존, `_normalized` 버전 또는 컬럼 추가 |

## 검토 필요 사항 (사용자 결정)

1. **표준명 기준**: 약칭(괴담출근)이 더 많이 쓰이면 약칭을 표준으로 할 것인가, 정식명(괴담에 떨어져도…)으로 강제 통합할 것인가?
2. **다중 작품 처리**: 한 부스가 여러 작품을 다룰 때 대표 작품을 어떻게 선정? (첫 번째? 빈도 높은 것?)
3. **시리즈 처리**: 앙상블스타즈 vs 앙상블 스타즈!! Music을 묶을 것인가 개별 유지할 것인가?
4. **정규화 적용 범위**: `대표 작품(원작)`만 할지, `그 외 다루는 작품`도 함께 할지?
5. **원본 보존**: 기존 컬럼을 덮어쓸지, 새 컬럼(예: `원작_정규화`)을 추가할지?
