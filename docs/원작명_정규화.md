# 원작명 정규화 (Works Normalization)

> 부스 데이터의 `대표 작품(원작)` 컬럼 정규화 규칙 정리
> 기준 코드: `vis.py`의 `preprocess_data()` / 분석 데이터: 26년_7월 (444개 고유 원작명)

## 정규화 파이프라인

```
원본 문자열
   │
   ▼
[1] 소문자 변환 + 앞뒤 공백 제거
   │
   ▼
[2] 다중 공백 → 단일 공백 (\s+ → ' ')
   │
   ▼
[3] 구분자 분할 (explode)
   │  ┌─────────────────────────────────┐
   │  │ ,  /  &  " and "  " 및 "        │
   │  └─────────────────────────────────┘
   ▼
[4] 유사 항목 그룹화 (매핑 사전 적용)
   │
   ▼
정규화된 원작명
```

## 구분자 규칙 (split)

| 구분자 | 비고 |
|---|---|
| `,` | 쉼표 |
| `/` | 슬래시 |
| `&` | 앰퍼샌드 |
| ` and ` | 영문 |
| ` 및 ` | 한글 |

## 그룹화 매핑 사전 (vis.py 기존)

| 변형 (key) | 정규명 (value) |
|---|---|
| `jujutsu kaisen` / `jujutsukaisen` / `jujutsu kaisen ` | `jujutsu kaisen` |
| `attack on titan` | `attack on titan` |
| `shingeki no kyojin` | `attack on titan` |
| `demon slayer` | `demon slayer` |
| `kimetsu no yaiba` | `demon slayer` |

> 영문/원어 표기를 공식 영문명으로 통일하는 방식

## 실제 데이터에서 발견된 정규화 필요 케이스

### A. 띄어쓰기 차이 (동일 작품)

| 표기 A (빈도) | 표기 B (빈도) | 제안 정규명 |
|---|---|---|
| `히프노시스마이크` (26) | `히프노시스 마이크` (21) | `히프노시스 마이크` |

### B. 조사/어미 차이 (동일 작품)

| 표기 A (빈도) | 표기 B (빈도) | 제안 정규명 |
|---|---|---|
| `괴담에 떨어져도 출근을 해야 하는구나` (94) | `괴담에 떨어져도 출근을 해야하는구나` (15) | `괴담에 떨어져도 출근을 해야 하는구나` |

### C. 소문자화 후 중복 발견

| 원본 변형 | 제안 정규명 |
|---|---|
| `헌터x헌터` / `헌터X헌터` | `헌터x헌터` |
| `내가 키운 s급들` / `내가 키운 S급들` | `내가 키운 s급들` |
| `아이돌마스터 sidem` / `아이돌마스터 SIDEM` | `아이돌마스터 sidem` |
| `100m` / `100M` | `100m` |

## 정규화 전후 효과 예시

```
[정규화 전] 히프노시스마이크: 26 / 히프노시스 마이크: 21  (별도 집계)
[정규화 후] 히프노시스 마이크: 47                          (통합 집계)
```

## 비고

- 현재 매핑 사전은 영문 작품 6개에 한정 → 한글 작품 띄어쓰기/조사 변형 대응 필요
- `preprocess_data()`는 런타임에 딕셔너리 replace 수행 → 사전 확장으로 즉시 적용 가능
- README.md에 "참가 작품명 딕셔너리 관리"가 파생 프로젝트(작업 예정)로 등록되어 있음
- 부스명 유사도는 `부스명 유사도 사전.csv`로 별도 관리 (원작명 정규화와 무관)
